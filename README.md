# KNP Sandbox

Интерактивная песочница для визуализации дистилляции и квантирования моделей.
Локальное приложение: Flask-фасад + C#/Blazor-ядро.

## Что внутри

- **Дистилляция**: teacher/student, temperature, alpha, learning rate,
  распределения вероятностей, метрики лосса, автосохранение в историю.
- **Квантирование**: битность 2–32, пресеты FP32/FP16/INT8/INT4/INT2,
  размер модели, сжатие, деградация perplexity.
- **Настройки**: 4 палитры, светлая/тёмная тема, dev-режим (пароль `1234`),
  список моделей, сброс состояния/истории.

## Требования

- **Python** 3.10+
- **.NET SDK** 9.0 или новее
